# Asistente de productos ATLAS

1. Descomprime la carpeta.
2. En Chrome abre `chrome://extensions`.
3. Activa **Modo de desarrollador**.
4. Pulsa **Cargar descomprimida** y selecciona esta carpeta.
5. Fija el asistente en la barra de Chrome.
6. Inicia sesión en Sonepar, abre un producto y pulsa el asistente.

La extensión solamente lee la página de producto que está abierta. No lee ni envía credenciales.
